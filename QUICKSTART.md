# MoxAbleton Quickstart

1. Install Ableton Live 11 and the AbletonOSC workflow used by the project.
2. Enable MoxAbleton and its required OSC support.
3. Open one of the included active Ableton Live projects under MozXR/Ableton; do not start from a Backup folder.
4. Open the correspondingly named Unreal example map family, configure endpoints in project configuration, and start both applications.
5. Trigger a send/listener event and confirm the matching event in the other application.

Included active Live 11 projects cover Listen, Rotation, Scene, and Song examples. The plugin includes matching Unreal example-map families.

**Verification:** a configured send is received by the listener and an Ableton-triggered event is visible in Unreal.
